The hard part: telco data does not say who booked a ride

An operator sees network traffic, not app screens. So each app's traffic had to be cut into sessions, each user classified as a driver or a customer, and each customer session classified as a transaction or just browsing, before any segment meant anything.

From behaviour to archetypes people recognise

Word2Vec embeddings of behaviour sequences place users with similar habits close together. Clusters in that space were named as archetypes a marketer can act on, and a look-alike model finds more people like each one.
