Research

Master's researcher in Smart Mobility at Hiroshima University. I build LLM feature-engineering pipelines that turn unstructured geospatial data into features for causal and econometric models. Current work tests whether LLM-scored place features improve welfare estimates for urban pricing policy, using NYC's January 2025 congestion toll as a natural experiment. The work covers LLM prompt design and reliability testing, causal inference (difference-in-differences), discrete-choice modelling and ablation-based model evaluation.

LLM-derived features for causal policy evaluation

Urban and Data Science Lab, Hiroshima University · 2026 – present

  • LLM feature pipeline. Llama-3 70B scoring of OpenStreetMap POIs and place names into 15 structured semantic features across 4 construct families: activity, physical environment, safety and built environment.
  • Prompt engineering and reliability. A versioned prompt library with staged probes to select wordings, repeated-run reproducibility testing, and a scorer chosen by training cutoff so it cannot have seen the policy period.
  • Causal evaluation. Difference-in-differences on millions of NYC TLC high-volume for-hire vehicle trip records around the January 2025 congestion toll.
  • Ablation design. A 4-arm ladder (no-LLM baseline, flat LLM features, latent-factor ICLV, embeddings) to measure what the LLM features add, with a SHAP-explained gradient-boosting robustness check.
  • Hybrid choice modelling. Factor analysis (N=262 zones) reduces the features to latent factors for an ICLV model; welfare comes from logsum consumer surplus, with price elasticity.
  • Pipeline engineering. Medallion layers (bronze, silver, gold) and multi-agent LLM tooling to coordinate the workflow.
